Lección 1

¿Qué es el álgebra?

El álgebra es el lenguaje que usamos para describir patrones y relaciones usando letras en lugar de números concretos. Una letra (como x) representa un número que todavía no conocemos.

Con números

3 + 3 = 6

Solo funciona para ese caso.

Con álgebra

a + a = 2a

Funciona para cualquier número.

Un ejemplo real

Un cuaderno cuesta x euros. Si compras 4 cuadernos, pagas 4x. Si además pagas 2 € de envío, el total es:

4x + 2

Esa expresión sirve para cualquier precio: si x = 3, pagas 14 €; si x = 5, pagas 22 €.

Lección 2

Variables y expresiones

Una variable es la letra. Una expresión es una combinación de números, variables y operaciones. No lleva signo =.

2x + 3

Expresión: se puede evaluar, pero no "resolver".

2x + 3 = 11

Ecuación: tiene un signo igual y una solución.

Lección 3

Resolver una ecuación lineal

Resolver una ecuación es dejar la x sola a un lado. La regla de oro: lo que haces en un lado, lo haces en el otro.

2x + 3 = 11

  1. Quita el 3 Resta 3 en los dos lados: 2x = 11 − 3 → 2x = 8
  2. Quita el 2 Divide entre 2 en los dos lados: x = 8 / 2 → x = 4
  3. Comprueba 2 · 4 + 3 = 8 + 3 = 11 ✓
Truco mental: si algo suma, pasa restando; si multiplica, pasa dividiendo. Pero cuidado: solo funciona si lo aplicas a toda la expresión.

Lección 4

Factorizar: el camino de vuelta

Multiplicar convierte un producto en una suma: (x + 2)(x + 3) = x² + 5x + 6. Factorizar es hacer el recorrido inverso: partir de la suma y escribirla como producto de factores más simples.

1. Factor común

6x² + 9x = 3x(2x + 3)

Buscamos lo que se repite en todos los términos: 3 y x.

2. Diferencia de cuadrados

x² − 9 = (x − 3)(x + 3)

Dos cuadrados que se restan: a² − b² = (a − b)(a + b).

3. Trinomio

x² + 5x + 6 = (x + 2)(x + 3)

Dos números que multiplican 6 y suman 5.

Ejemplo resuelto paso a paso

x² + 5x + 6

  1. Paso 1: busca dos números Deben multiplicarse y dar 6, y sumarse y dar 5. Prueba: 2 · 3 = 6 y 2 + 3 = 5. ✓
  2. Paso 2: escríbelos como factores (x + 2)(x + 3)
  3. Paso 3: comprueba multiplicando (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6 ✓
Regla práctica: factoriza siempre en este orden: factor común → diferencia de cuadrados → trinomio. Si empiezas por el factor común, el resto suele salir solo.
