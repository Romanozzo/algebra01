# Álgebra desde cero

Página web educativa para aprender álgebra básica, con lecciones y ejercicios interactivos.

## Contenido

- **Lección 1** — ¿Qué es el álgebra?
- **Lección 2** — Variables y expresiones (con deslizador interactivo)
- **Lección 3** — Resolver ecuaciones lineales (paso a paso)
- **Lección 4** — Factorización: factor común, diferencia de cuadrados y trinomios
- **Práctica** — 8 preguntas con corrección instantánea y puntuación

## Tecnologías

HTML, CSS y JavaScript puro. Sin frameworks ni dependencias.

## Cómo ejecutarlo

Abre `index.html` en el navegador, o levanta un servidor local:

```bash
python -m http.server 8000
```

Y visita <http://127.0.0.1:8000>.

## Estructura

| Archivo | Función |
| --- | --- |
| `index.html` | Estructura y contenido |
| `styles.css` | Diseño y estilos |
| `script.js` | Interactividad y cuestionario |
